# tgupbot — Telegram 资料收录机器人

一个 Telegram 机器人，允许管理员收录一组图文资料，自动发布到主频道，并根据"现居"字段自动转发到对应省份频道。

## 功能

- 管理员点击「收录资料」按钮进入收录模式
- 机器人提示"请转发一组资料到这里"
- 管理员转发任意数量的消息（文字、图片、视频、文件、相册）
- 点击「完成收录」后，机器人自动：
  1. 将所有消息发送到主频道
  2. 从资料文本中的 `现居：<省份>` 字段识别地区
  3. 若识别成功且已配置对应省份频道，则自动转发到该频道

## 安装

```bash
pip install -r requirements.txt
```

## 配置

1. 复制 `.env.example` 为 `.env`：

   ```bash
   cp .env.example .env
   ```

2. 填写 `.env` 中的配置项：

   | 变量 | 说明 |
   |---|---|
   | `BOT_TOKEN` | BotFather 提供的机器人 Token |
   | `ADMIN_IDS` | 管理员的 Telegram 用户 ID，多个用逗号分隔 |
   | `MAIN_CHANNEL` | 主频道 ID 或用户名（如 `@mychannel` 或 `-1001234567890`） |
   | `CHANNEL_<省份英文>` | 各省份对应的频道 ID 或用户名（可选，只需填写需要的省份） |

   > **注意**：机器人必须是主频道和各省份频道的**管理员**，才能发送消息。

3. 在资料文本中加入 `现居：<省份>` 一行（支持中文全角冒号 `：` 或半角冒号 `:`），例如：

   ```
   现居：广东
   ```

## 运行

```bash
python bot.py
```
